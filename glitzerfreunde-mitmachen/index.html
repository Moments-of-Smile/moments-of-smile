Die Glitzerfreunde brauchen deine Fantasie

In meinem Kreativbuch soll es eine besondere Mitmachseite geben. Kinder können dort eigene Ideen, Figuren oder kleine Glitzerwald-Momente gestalten.

Wer mitmachen möchte, kann die kreative Seite ausfüllen, bemalen oder fotografieren und sie zusammen mit der Einverständniserklärung per E-Mail einsenden.

So funktioniert die Mitmachaktion

  1. Gestalte deine Idee für die Welt der Glitzerfreunde.
  2. Lade die Einverständniserklärung herunter.
  3. Lass die Einverständniserklärung von einem Elternteil oder einer erziehungsberechtigten Person ausfüllen.
  4. Sende ein Foto oder einen Scan deiner Kreativseite zusammen mit der Einverständniserklärung per E-Mail.

E-Mail: Moments_of_smile_official@web.de

Einverständniserklärung für Eltern

Damit Einsendungen sicher und ordentlich verwendet werden können, brauche ich eine ausgefüllte Einverständniserklärung von einem Elternteil oder einer erziehungsberechtigten Person.

Einverständniserklärung herunterladen

Hinweis: Der Download funktioniert erst, wenn die PDF-Datei ebenfalls bei GitHub hochgeladen wurde.

Wichtig

Bitte sende keine privaten Daten von Kindern mit, die nicht gebraucht werden. Für die Mitmachaktion reicht später zum Beispiel ein Vorname, Spitzname oder Fantasiename.

Nicht jede Einsendung kann automatisch veröffentlicht oder verwendet werden. Eine Auswahl kann später auf der Webseite, in Social Media oder im Zusammenhang mit dem Buchprojekt gezeigt werden, wenn die Einverständniserklärung dafür vorliegt.
